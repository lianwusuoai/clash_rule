## 📝 规则类型说明

- `DOMAIN` - 精确域名匹配
- `DOMAIN-SUFFIX` - 域名后缀匹配
- `DOMAIN-KEYWORD` - 域名关键词匹配
- `IP-CIDR` - IPv4 地址段匹配
- `IP-CIDR6` - IPv6 地址段匹配
- `IP-ASN` - ASN 自治系统号匹配
- `PROCESS-NAME` - 进程名匹配
